# AFK Rome Village

Репозиторий раннего браузерного прототипа idle-игры о развитии римской деревни и автоматической защите от волн орков.

## Быстрый запуск

Из корня репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

Затем открыть <http://127.0.0.1:4173>.

Установка зависимостей, сборка и backend не нужны.

## Что где лежит

- [`references/`](references/) — композиционные и прогрессионные референсы.

## Текущее состояние

Прототип демонстрирует ферму, улучшения, автоматический бой, поражение и повтор волны, босса пятой волны, открытие лучника, паузу, ускорение и сброс прогресса.

Ближайший продуктовый шаг — проверить игровой цикл с игроками и зафиксировать решения по поражению, доступу к следующей волне и роли героя. После этого можно выбирать production-стек и переносить механику из однофайлового прототипа в нормальную архитектуру.
