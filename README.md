# AFK Rome Village

Репозиторий раннего браузерного прототипа idle-игры о развитии римской деревни и автоматической защите от волн орков.

## Быстрый запуск

Из корня репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

Затем открыть <http://127.0.0.1:4173>.

Установка зависимостей, сборка и backend не нужны.

## Текущее состояние

Объединены наша версия и Test1.zip: один легионер на старте, 1–5 врагов в волне, развитие поселения после боссов, растущая деревня, выбор лучника или катапульты. У каждого героя свой спелл, слоты героев открываются с поселением (1/2/3), есть ротация с усталостью и «Свежими силами» — см. prototype/README.md. Сохранены наши иконки, лучник, восстановление и бот балансировки.

Проверки: `node prototype/tests/wave-balance.cjs` и `node prototype/tools/balance-bot.cjs`. Сохранений и офлайн-дохода пока нет. Баланс второго акта требует ручного плейтеста.
